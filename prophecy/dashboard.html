Paste one block of settings into your coding agent. After that, every agent that opens this project checks in on its own.

This is the part that matters. An agent writing code here does not have to guess who else is in the codebase — it asks, over MCP, and gets an answer built from this project's real dependency graph. And it works both ways: when you send an agent the risk profile of what it is doing, that reading is waiting for it the next time it asks anything.

The agent asks
  • join_repo_session — who else is here, and what they have already worked out
  • analyze_change — what this change would break, before committing it
  • check_overlap — whether these files are somebody else's files too
  • get_change_interactions — what this change looks like next to everything else in flight
  • share_finding — hands something back for the next agent that goes there
Prophecy answers
  • a risk score with its range and confidence, not a verdict
  • the files and callers that would actually be hit
  • the other work it is about to collide with, by name
  • anything you sent from , delivered on the agent's next call
